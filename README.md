# Десктопный помощник

Десктопное приложение-помощник с персонажем на рабочем столе.
Курсовой проект по дисциплине «Проектирование программного обеспечения», ИКИТ СФУ.
Студента Грибенщикова Алексея Сергеевича ЗКИ24-17

## Возможности

- Персонаж на рабочем столе без обычного окна (по умолчанию — Рик).
- Смена картинки и имени персонажа; выбор сохраняется между запусками.
- Сворачивание в системный трей.
- Создание команд трёх типов: открыть папку, открыть файл, выключить компьютер.
- Выполнение и удаление команд через меню.

## Требования

- Windows 10 или 11
- Python 3.9 или новее
- Библиотека PyQt6

## Установка и запуск

Установите зависимость командой: pip install PyQt6

Запустите программу из папки проекта командой: python main.py

## Как пользоваться

- Левая кнопка мыши по персонажу — перетаскивание по экрану.
- Правая кнопка мыши по персонажу — меню: создать команду, выполнить команду, сменить картинку и имя, свернуть в трей, выход.
- Клик по значку в трее — показать или скрыть персонажа.

## Структура проекта

- main.py — запуск приложения
- character.py — персонаж на рабочем столе
- command.py — команда и её типы
- command_manager.py — хранение и выполнение команд
- tray_icon.py — значок в трее
- windows.py — окна создания и выполнения команд
- docs/ — UML-диаграммы
- images/ — картинки персонажа
